# 소스코드 기반 AI 테스트 자동화 — 지침 모음

앱 소스코드와 정책 문서를 사내 AI로 분석해서 **화면·요소 카탈로그 → 테스트케이스 → 자동 테스트 스크립트 → 스케줄 운영**까지 진행하기 위한 문서입니다.

| 파일 | 대상 | 내용 |
|---|---|---|
| [00_분석_검토.md](00_분석_검토.md) | 사람 (의사결정) | 소스 기반 방식의 타당성, 한계, 전체 구조, 리스크, 개발팀 요청 사항 |
| [01_공통지침.md](01_공통지침.md) | **사내 AI** | 시스템 프롬프트: 역할, 안전·근거·보안 규칙, 출력 규칙 |
| [02_단계별_프롬프트.md](02_단계별_프롬프트.md) | **사내 AI** | P0~P10 단계별 업무 지시 프롬프트, 보정 프롬프트 |
| [03_산출물_스키마.md](03_산출물_스키마.md) | **사내 AI** + 사람 | 카탈로그·TC·스크립트 형식 정의 |
| [04_검토_운영_가이드.md](04_검토_운영_가이드.md) | 사람 (실무) | 단계별 검토 체크리스트, 진행 계획, CI 운영, 지표 |

## 빠른 시작

1. `00_분석_검토.md`를 읽고 파일럿 영역을 정합니다.
2. `01_공통지침.md`의 설정값(`{{ }}`)을 채워 사내 AI의 시스템 프롬프트로 등록합니다.
3. `03_산출물_스키마.md`를 함께 제공합니다.
4. `02_단계별_프롬프트.md`의 P0부터 순서대로 보내고, 각 단계 결과를 `04_검토_운영_가이드.md` 체크리스트로 검토합니다.

## 이 저장소의 기존 도구와의 관계

- `crawler.py` / `sitemap.json`: P6 런타임 대조의 입력(실제 앱 화면·요소)
- `config.py`의 `DRIVING_BLACKLIST_KEYWORDS`, `PAYMENT_BLACKLIST_KEYWORDS`: 공통지침 안전 규칙과 스크립트 안전 가드의 기준. 한쪽을 바꾸면 다른 쪽도 같이 바꿉니다.
- `run_stage.sh`: 스케줄 실행 작업의 출발점
