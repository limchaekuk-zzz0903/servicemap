# 초등 3학년 수학 학습지 리서치 & 설계 노트

> 대상: 초3 · 범위: 곱셈·나눗셈(복습), 분수(첫 개념 학습)
> 참고: 사용자가 공유한 네이버 링크(naver.me/GLhW9XW0)는 작업 환경에서 접속이 차단되어 내용을 확인하지 못했다. 아래 분석은 일반적으로 알려진 학습지·교재 유형을 바탕으로 정리했다.

## 1. 학습지·교재 유형 분석

| 유형 | 대표 예 | 강점 | 한계 | 이 프로젝트에 가져온 것 |
|---|---|---|---|---|
| 방문/구독형 단계 학습지 | 구몬, 눈높이, 재능 등 | 아주 작은 단계로 매일 조금씩, 반복으로 계산 속도 향상 | 왜 그런지 설명은 적고 지루해지기 쉬움 | 한 화를 10~15분 분량으로 쪼갬, 문제마다 숫자가 바뀌는 무한 반복 |
| 연산 반복 문제집 | 기적의 계산법, 소마셈 등 | 하루 분량이 명확, 실수 유형을 반복 교정 | 개념 이해보다 절차 암기에 치우침 | 세로셈을 한 단계씩 보여 주는 "다음 단계" 조작 |
| 개념·유형 문제집 | 디딤돌, 쎈, 개념원리 계열 등 | 교과 단원과 정확히 맞물림, 난이도 단계 | 글이 많아 스스로 읽기 어려워함 | 교과 단원 매핑(3-1·3-2), 화마다 "오늘의 목표" |
| 학습 만화 | 수학도둑, Why? 수학 계열 등 | 캐릭터와 이야기로 몰입, 자발적으로 읽음 | 읽고 끝나면 연습이 부족 | 만화 → 바로 조작 → 바로 문제로 이어지는 구조 |
| 만화+심화 결합 | Beast Academy(미국) | 만화 속 캐릭터가 개념을 토론하고 바로 문제집으로 연결 | 영어, 난이도 높음 | 캐릭터가 "틀린 풀이"를 보여 주고 아이가 고치는 장면 |
| CPA 교수법 | 싱가포르 수학 | 구체물(Concrete) → 그림(Pictorial) → 식(Abstract) | 교구 준비 부담 | 화면 속 교구(피자, 막대, 사탕 묶음, 보석 바구니) |
| 게임형 앱 | Prodigy, Khan Academy Kids 등 | 보상·진행감, 즉시 피드백 | 보상만 쫓고 개념이 남지 않을 수 있음 | 별 3개·크리스탈 수집, 단 별은 "첫 번째에 맞힌 수"로만 |

## 2. 3학년 아이들이 자주 하는 실수 (설계의 핵심)

이 실수들을 악당 캐릭터 **뚱땅이**의 대사로 넣어서, 아이가 "아니야!" 하고 고치는 경험을 하게 했다.

- **곱셈**: 올림을 빠뜨리거나, 각 자리 곱을 그냥 붙여 씀 (26 × 3 = 618)
- **나눗셈**: 나눗셈을 뺄셈으로 처리 (24 ÷ 6 = 18), 나머지가 나누는 수보다 큼 (17 ÷ 5 = 2 … 7)
- **분수**
  - 크기가 다른 조각도 분수라고 생각 (똑같이 나누지 않음)
  - 분모·분자 위치와 읽는 순서 혼동 ("3분의 4")
  - 자연수 감각을 그대로 적용: 분모가 크면 더 큰 분수라고 생각 (1/8 > 1/2)
  - 분수 덧셈에서 분모끼리 더함 (1/4 + 2/4 = 3/8)

## 3. 설계 원칙

1. **스토리 한 줄**: 멈춘 시계탑 → 세 지역에서 크리스탈 찾기 → 시계탑이 다시 움직임 → 인증서. 아이가 "다음 화"를 누를 이유를 만든다.
2. **캐릭터 역할 분담**: 하루(아이 자신, 추론하는 역할) · 셈이(개념을 정리해 주는 선생님) · 뚱땅이(오개념을 대신 저질러 주는 역할). 틀리는 건 뚱땅이라서 아이가 부담 없이 비판적으로 생각할 수 있다.
3. **한 화의 흐름 = CPA**: 만화(왜 필요한가) → 직접 해 보기(그림 조작) → 도전 문제 5개(식).
4. **복습과 신규의 차이**
   - 곱셈·나눗셈(복습): 화당 개념 설명은 짧게, 실수 교정과 3-2 확장 내용(세 자리 × 한 자리, 두 자리 × 두 자리, 나머지·검산) 위주.
   - 분수(신규): 6화로 잘게 나눔. 똑같이 나누기부터 시작해 단계마다 그림을 반드시 먼저 보여 준다.
5. **피드백**: 1차 오답은 힌트, 2차 오답은 정답과 풀이. 실패해도 막히지 않게 한다.
6. **반복 가능성**: 모든 문제를 난수로 생성해 같은 화를 다시 풀어도 숫자가 바뀐다.

## 4. 커리큘럼 맵

| 지역 | 화 | 내용 | 교과 연결 |
|---|---|---|---|
| 곱셈 숲 (복습) | 1 | 묶어 세기, 곱셈구구, 교환법칙 | 2학년 곱셈구구 → 3-1 곱셈 |
| | 2 | 올림이 있는 (두 자리) × (한 자리) 세로셈 | 3-1 곱셈 |
| | 3 | (세 자리) × (한 자리), (두 자리) × (두 자리) 쪼개 곱하기 | 3-2 곱셈 |
| 나눗셈 동굴 (복습) | 1 | 똑같이 나누기, 묶어 덜어 내기 | 3-1 나눗셈 |
| | 2 | 곱셈과 나눗셈의 관계, (두 자리) ÷ (한 자리) | 3-1·3-2 나눗셈 |
| | 3 | 나머지, 검산 | 3-2 나눗셈 |
| 분수 성 (신규) | 1 | 똑같이 나누기 | 3-1 분수와 소수 |
| | 2 | 분모·분자, 읽고 쓰기 | 3-1 분수와 소수 |
| | 3 | 단위분수·분모가 같은 분수 크기 비교 | 3-1 분수와 소수 |
| | 4 | 묶음을 분수로, 전체의 몇 분의 몇 | 3-2 분수 |
| | 5 | 진분수·가분수·대분수 | 3-2 분수 |
| | 6 | 분모가 같은 분수의 덧셈·뺄셈 | 4학년 미리보기 |

## 5. 앱으로 확장하는 방법

- **지금 바로**: `index.html`은 PWA(manifest + service worker)로 구성되어, HTTPS로 배포하면 휴대폰·태블릿에서 "홈 화면에 추가"로 앱처럼 설치되고 오프라인에서도 열린다.
- **스토어 출시**: 같은 웹 코드를 Capacitor로 감싸면 Android/iOS 앱으로 빌드할 수 있다.
- **다음 단계 후보**: 음성 읽어 주기(만화 대사 TTS), 부모용 학습 리포트, 오답 노트, 4학년 분수·소수 지역 추가, 실제 일러스트 교체.
