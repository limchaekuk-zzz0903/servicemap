# 리뷰 반영 기록

두 리뷰어(초등 학부모 관점, 초등 학습지 전문 강사 관점)의 피드백을 모아 개선 항목을 정리하고 반영한 결과입니다.

- 학부모 리뷰: 화면을 직접 보고 아이 혼자 학습, 동기, 부모 관리, 신뢰, 모바일 사용성을 점검
- 강사 리뷰: 42화 × 50회(약 10,500문항)를 생성해 수학 오류, 교육과정 정합성, 문항 설계, 해설 품질을 점검. 계산 정답 오류는 0건

## 반영한 항목

| 구분 | 지적 (출처) | 반영 내용 |
|---|---|---|
| 표기 | "이(가)·와(과)·(으)로" 병기, "7를·18가·1예요" 같은 조사 오류 (학부모·강사) | 앞 단어·숫자·분수의 받침을 읽어 조사를 자동으로 고르는 기능을 문제, 힌트, 풀이, 보기, 만화, 위젯에 적용. 생성 문항 전체에서 병기 표기 0건 확인 |
| 정확성 | 받아올림 힌트 "10보다 크면" (강사) | "10이거나 10보다 크면"으로 수정 |
| 정확성 | 의미 없는 값: 7 : 7, 80 = 80 + 0, 130 × 0, "11 → 11" (강사) | 값 범위 조정 |
| 채점 | 크기가 같은 분수(3/6과 1/2, 6 2/4와 6 1/2)를 오답 처리 (강사) | "기약분수로"를 요구하지 않는 문항은 크기가 같으면 정답 |
| 문구 | "위의 말을", "배 수", "왼쪽에서 7번째 숫자", canyon-3 비 설명 비약, seed-1 같은 인물의 문답 (학부모·강사) | 문구 수정, 자리 이름(천만의 자리 등)으로 질문, 레몬즙 : 전체 주스 = 2 : 5로 이어서 설명, 뚱땅이가 틀리고 셈이가 바로잡도록 수정 |
| 문항 | 한 세트에 같은 문항 반복 (강사) | 같은 문항이 나오면 같은 칸에서 다시 생성. 문제지도 중복 없이 구성 |
| 문항 | 5학년 대분수 계산·곱셈 없음, 몫에 0을 채우는 소수 나눗셈 없음, 같은 우선순위 혼합 계산 없음, 최대공약수·최소공배수 활용 없음, 축척 1 cm 고정, 대분수가 정답인 분류 없음, 나눗셈의 두 번째 뜻이 정답으로 안 나옴, 1분 단위·몇 분 전 시각 없음, 소수 세 자리 없음 (강사) | 각 유형 생성기 추가 |
| 교육과정 | 9까지의 수, 짝수·홀수와 (몇십몇)±(몇십몇), 몇의 몇 배, 네 자리 수, 세 자리 수의 덧셈·뺄셈, 분수와 소수, 수의 범위와 어림 누락 (강사), 1학년 분량 부족 (학부모) | 7화 추가: 전체 49화. 1학년 8화, 2학년 8화, 3학년 14화, 4·5·6학년 6~7화 |
| 대장 문제 | 힌트 후 정답도 인정, 찍기로 통과 가능 (강사) | 첫 번째 시도에 6문제 중 4문제 이상 맞혀야 통과 |
| 오답 | 틀린 문제를 다시 볼 수 없음 (학부모·강사) | 결과 화면에 틀린 문제와 풀이 표시, 오답 노트(자동 저장, 다시 풀기, 오답 문제지 인쇄) |
| 부모 관리 | 학습 기록 없음, 아이별 구분 없음 (학부모) | 학습 기록 화면(7일 학습 횟수, 정답률, 시간, 학년별 진도, 다시 볼 화), 아이별 프로필 |
| 읽기 | 1학년이 읽기 어려움, 손글씨체, 낱말 중간 줄바꿈, 읽어 주기 없음 (학부모) | 만화 칸·문제 읽어 주기(음성 합성), 만화 전체 듣기, 1·2학년 말풍선은 본문 글씨, 낱말 단위 줄바꿈 |
| 화면 | 대장 문제에서 학년 표시 틀림, 질문 버튼이 만화를 가림, 휴대폰에서 제목 줄바꿈, 다음 화 안내 없음, 추천 질문이 학년과 무관 (학부모) | 각각 수정. 학년별 추천 질문과 기본 도움말 낱말 추가 |
| 출력 | 출력용 학습지 필요 (학부모·강사) | 화별 문제지 10문항, 단원 문제지 최대 20문항, 정답과 풀이지(복습할 화 표시), A4 인쇄 |

## 남겨 둔 항목 (다음 단계)

- 학년당 9~12화로 더 늘리기(현재 1·2학년 8화, 4~6학년 6~7화)와 도형·측정 단원
- 화당 기본 3·응용 1·심화 1 구성으로 문항 단계를 명확히 하기, 두 단계 문장제 확대
- 대장 문제 전용 통합 문항, 풀이지의 "틀리기 쉬운 점" 한 줄, 성취기준 코드 표기
- 글씨체를 파일 안에 넣어 오프라인에서도 같은 글씨로 보이게 하기
- 흑백 인쇄용 무늬 처리
